## 目的
- 让相关工作能够利用已经确认的未来方向，同时保持当前基线、任务范围和未来先后关系各自清楚。

## 背景
- `active` 表示方向已经确认且当前适用，`alignment` 只说明完整方向是否已经成为当前事实。
- 未对齐方向是已经确认的未来方向；当前任务另行提供实施授权、范围和优先级。
- 相关工作需要在满足本次任务的可行方案中考虑未来方向，实际实施范围仍由当前任务确定。

## 决策
- 采用: `active + unaligned` 表示已经确认但尚未成为当前事实的未来方向。
- 采用: 相关工作将该方向作为未来演进输入，在完整满足当前任务的可行方案中优先保留通向该方向的路径；实施内容保持在当前任务明确要求内。
- 采用: 对齐状态表达方向与当前事实的关系；本次实施范围由当前任务确定，未来先后关系由决策正文表达。
- 采用: 完整方向成为当前事实后标记为已对齐；方向发生变化时通过决策演进维护。
