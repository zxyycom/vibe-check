# 规模收益、代价与采用边界

## 结论与硬证据

采用这次 Markdown Link 私有引用图：在不缩小 source scope、不合并重复引用 Finding、不中断授权边界的前提下，
热点 target probe 从按引用增长改为按逻辑节点取得一次观察。source/target 角色重叠时复用已授权读取的源事实。

操作量硬门禁已通过：8,000 条深 32 热点引用的 lstat 为 **264,001 → 34**，逻辑 targetReadCount 仍为 8,000；
唯一目标同场景仍为 264,001 → 264,001，不能把共享目录前缀或相同 bytes 当作合并节点的授权。
额外循环、源复用、缺失、目录单 entry、无内容需求与别名证明见 [操作量证据](operations.md)。
正确性、完整发布、预算/取消、路径授权和 cache lifecycle 由产品测试、Case 与最终同 candidate **43/43 Gate** 交叉验证。

## 五对正式计时与 RSS

最终 27 组均为 warmup 后五对独立 Node 24.18.0 进程，保留交替 pair order。
完整重要场景、每组中位数/MAD、RSS 与比值见 [完整对照](comparison.md)及 `summary.json`，不是跨不同输入的平均数。

- **热点**：所有规模/深度/cache 组都观察到降低。8k/深32关闭缓存中位数 **25,094.0 → 906.1 ms**；
  命中缓存为 **28,745.4 → 138.6 ms**。这是同输入、同有限配置的完成执行，不是把旧超限退出与新完成比较。
- **唯一目标**：没有节点复用的渐进收益，保持必要探测与正文读取。耗时比值约 0.872–1.058；不把小幅波动一概解释为改进。
  8k/深3/hit 中位数 **7,340.5 → 7,763.0 ms**（约 **+5.8% / +422.5 ms**），是明确保留的局部代价。
- **冻结真实 corpus**：361 源、2,343 occurrences、1,939 计费边。关闭/空/hit cache 的中位数分别为
  **3,648.8 → 3,023.6 ms**、**3,373.5 → 3,042.7 ms**、**1,116.7 → 835.8 ms**。
- **空间取舍**：图保留节点、边及标题事实，原文与 AST 不全量持有；空间随节点和边增长。
  RSS 不保证下降：unique 8k/深32/off 为 **338.3 → 352.4 MiB**；真实 empty 为 **282.8 → 315.6 MiB**（约 +32.8 MiB）；
  真实 off 则为 341.6 → 311.4 MiB，hit 为 348.2 → 352.2 MiB。RSS 是整个进程峰值，包含 fixture setup 和 hit prefill，
  不能当作只属于 timed Run 的精确增量；完整 median/MAD 保留在 JSON。

## 采用理由与限制

按[规模收益取舍](../../../docs/decisions/weigh-performance-costs-against-scaling-benefits.md)，接受无复用输入的有限调度/图状态开销，
换取重复引用增长、源角色复用、固定 missing 观察与真实事件循环协作取消；不要求每场景更快，不新增毫秒、百分比或 MiB 硬阈值。
该结论仅覆盖已冻结的代表性形状与真实 corpus，不知道全部用户负载分布，不承诺任意项目都加速。

OS page cache 未清空；只覆盖这台 Linux/WSL2 主机和固定 runtime/依赖。操作计数与计时分开，普通 full Gate 也未并发。
观察不是全文件系统原子快照；跨平台 hostile replacement isolation、同步解析内抢占与进程资源隔离不在已有保证内。

最终 Gate 按既有 warning-only policy 保留 mean **2167.8 ms > 2000 ms**、p95 **5345.1 ms > 5000 ms** 的提醒，43 项仍通过；
未修改预算、阈值或解释规则。预算关闭的 10,001 引用执行另由真实文件 fixture 正确性测试证明；有限 10,000 仍 unavailable，
该超上限验收不参与任何 before/after 加速结论。
