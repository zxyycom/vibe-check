# 操作量硬门禁

独立于正式计时的 59 个计数进程全部完成并通过断言：54 个矩阵版本/缓存组合，另有 5 个需求证明。
计数是异步 JavaScript fs API 调用，不宣称覆盖所有 syscall 或同步 source discovery。hit 行包含预填充和最终 Run，
故两次 invocation 的计数合并；下表 off 行只有一次 Run。逻辑 targetReadCount 始终逐引用，不随节点复用减少。

| 输入 | 边数 | 深度 | before lstat | after lstat | before open | after open |

| hot | 1000 | 3 | 4001 | 5 | 2 | 2 |
| hot | 1000 | 32 | 33001 | 34 | 2 | 2 |
| hot | 8000 | 3 | 32001 | 5 | 2 | 2 |
| hot | 8000 | 32 | 264001 | 34 | 2 | 2 |
| unique | 1000 | 3 | 4001 | 4001 | 1001 | 1001 |
| unique | 1000 | 32 | 33001 | 33001 | 1001 | 1001 |
| unique | 8000 | 3 | 32001 | 32001 | 8001 | 8001 |
| unique | 8000 | 32 | 264001 | 264001 | 8001 | 8001 |

真实 corpus（361 源 / 2,343 occurrences / 1,939 计费引用）每 invocation：lstat 从 9,081 降为 5,961，
正文 open 从 402 降为 364；关闭、空与命中缓存的关系相同。命中计数进程有两次 Run，raw 中相应翻倍。

额外需求证明：

- 源互引/循环共 1,001 条计费边，只 open 两个所选源（lstat=2 / open=2），不新增目标正文读取。
- 1,000 条缺失引用固定一次缺失观察（lstat=2 / open=1），只读取源正文。
- 1,000 条目录引用只 opendir 一次、读取一个 entry；不递归。
- 无 anchor 的 Markdown 目标即便含无效 UTF-8 也不读取其正文（open=1，仅源），仍完成存在性验证。
- 两个指向同一物理文件的逻辑 alias 仍分别观察（lstat=5 / readlink=2 / open=3），不按 inode/realpath 合并。

因此热点探测由按边增长降为按逻辑节点增长；唯一目标仍按每节点/每边各自进行必要探测和正文读取，
未利用公共前缀或解析缓存跳过新的授权 I/O。冻结源码身份及相关安全/取消/预算测试和完整 Gate 独立支持这些计数。
