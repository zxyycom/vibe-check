# Proposal

本 Draft 规划 Markdown Link 的轻量图式重构，以分离节点事实与引用边的方式支持持续增长的文档索引。

## Why

调查报告、证据附件和多层文档索引会持续增加本地引用。当前逐引用验证已复用部分解析事实，
但目标需求与节点操作仍分散在引用处理流程中，重复引用会反复触发路径授权与目标探测。

本 Change 将引用关系显式建模，由边的需求组织目标事实获取和逐引用判断。
同时调整按引用次数消耗的总量预算，使预算契约适配完整规模验证。

## Outcome

- Check 内分别保存节点事实与引用边，按引用需求组织节点操作，明确单次 invocation 的事实复用规则。
- 在既有完整输入范围和安全边界内，保留逐引用诊断与稳定结算，并用测量验证重构的操作量、耗时和资源代价。
- 配套提供总量预算的显式关闭方式，区分 Product 默认保险与调用方选择；预算调整不能替代图式重构的完成验收。

设计方向、受影响契约和进入 Plan 前的问题见 [Design](design.md)。
