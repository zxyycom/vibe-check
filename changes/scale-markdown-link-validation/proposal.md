# Proposal

本 Draft 规划支持持续增长文档索引的 Markdown Link 验证能力。

## Why

调查报告、证据附件和多层文档索引会持续增加本地引用。当前 `maxTargetReads` 按每次目标验证计费，
包括重复引用和缓存命中；因此总量预算可能阻断正常增长，而计数本身也不能反映实际 I/O 成本。

本 Change 分别处理规模选择与性能成本：提供显式关闭总量预算的能力，并按测量结果评估重复目标工作的复用。

## Outcome

- 仓库 Gate 可显式关闭总量预算，在既有完整输入范围、逐引用诊断和安全边界内验证增长后的文档。
- Product 将默认工作量保险与调用方显式选择分开，明确预算、关闭方式和计数契约。
- 目标事实复用作为独立的优化候选，以操作量、耗时、资源和维护成本决定采用；预算能力可先行交付。

设计方向、受影响契约和进入 Plan 前的问题见 [Design](design.md)。
