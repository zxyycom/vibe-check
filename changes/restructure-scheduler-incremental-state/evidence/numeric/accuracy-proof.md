## 1. Exact target and independently specified direct baseline

Inputs are the exact real values denoted by finite binary64 clock samples, the existing sample/state ownership trace, and nonnegative integer weights. `running` and pending category counts are task cardinalities; root/effective capacities are positive safe-integer maxParallel values or minima thereof. Weights are dimensionless, so outputs retain ms, task·ms, or slot·ms. No clock sampling boundary or public resolution changes.

For each delivered scalar result, restrict the trace to its own contributing intervals (including category membership and action-prefix boundaries). Let a_i <= b_i be consecutive samples, w_i its integer weight (or 1 for category delay/control/wait), x_i = w_i(b_i-a_i), and S = sum x_i >= 0. Zero-weight contributions may be omitted. The direct baseline is fl(sum_i fl(w_i fl(b_i-a_i))) with nonnegative left-to-right summation. It is defined independently of any lazy candidate, grouping, or global prefix. Empty S is exactly zero.

Let u=2^-53, eta=2^-1074. On the finite/no-overflow domain, each subtraction, integer-weight multiplication, or addition is either exact or obeys fl(z)=z(1+delta), |delta|<=u. Every exact operand/result is an integer multiple of eta. Thus a subnormal exact result of these operations is representable exactly; there is no additional underflow loss to hide in a tolerance. A multiplication by safe integer cannot create a fractional eta quantum. This observation is specific to the integer weights verified above, not a claim for arbitrary floating multipliers.

Each term passes through at most n+2 rounded operations (difference, product, at most n additions); for (n+2)u<1, the standard nonnegative forward bound is |baseline-S| <= gamma_(n+2) S, gamma_k=ku/(1-ku). Exact steps and zero terms can sharpen this bound but are not needed. A local segment/result uses its own n and S, never the entire Run's cumulative magnitude. For n=1, the bound includes difference/product/addition, even if an implementation elides an exact operation. For n=0 the output is exact zero.

Outside that relative-bound domain (overflow in an intermediate or nu>=1), the candidate must separately preserve exact target rounding/availability. In particular, a zero-weight product must not inherit an overflowing private elapsed prefix, and a history-only private prefix is not itself a delivered scalar. No empirical epsilon or fixed time resolution is introduced.

## 2. Candidate representation and error proof

Represent every finite Number t as the signed integer Q(t)=t/eta, obtained exactly from its binary64 sign/exponent/fraction bits. A normal Number with exponent field e and 53-bit significand m has Q(t)=sign*m*2^(e-1); a subnormal has Q(t)=sign*fraction. All operands are exact BigInts. Intervals Q(b)-Q(a), multiplication by integer weights, nonnegative accumulation, category prefix subtraction, and action-prefix subtraction are exact integer arithmetic. BigInt prefixes are not converted to Number merely because they exist.

At a public numeric checkpoint, round the exact nonnegative integer U back to binary64 once using round-to-nearest, ties-to-even. For bit length L<=53, U*eta is exact. Otherwise retain the highest 53 bits, compare discarded bits with half an ulp, and increment on greater-than-half or half with odd retained significand. Scale the resulting 53-bit integer by an exactly representable power of two. Carry into the next exponent is handled by the same rule. Overflow occurs exactly at the round-to-nearest overflow threshold, including the tie that rounds to Infinity: U >= (2^54-1)*2^2044. Below that threshold the rounded output is finite; subnormal outputs are exact integer eta multiples.

Therefore candidate output equals RN(S), the closest binary64 value to the exact result (ties even). For finite normal outputs |RN(S)-S|<=uS; for subnormal output it is exact. This is no worse than the independently frozen direct bound on every local result. Huge unrelated prefixes cancel exactly and do not enlarge the result's error bound: e.g. RN((P+eta)-P)=eta even if RN(P+eta)=RN(P), and even if P itself rounds to Infinity. Long sequence length affects integer storage, not arithmetic error. There is no floating-point subtraction of rounded global totals.

## 3. Lazy category representation and discrete correctness obligations

Reuse Core's equivalence groups: identical canonical resource claims (including units), mutex-ID set, tighter-scope/activation dimension. Do not aggregate heterogeneous claims merely by resource ID. Core's same-source local query distinguishes mutex, local capacity (named resource / inactive activation cap), and shared root/active-scope capacity. Maintain reverse constraint-to-group indexes only when a measurement collector actually exists.

A single shared gate controls root/active-scope capacity. Its two exact clocks accumulate globally-open and globally-closed durations. A group stores exact settled category clocks plus a baseline in those shared clocks or in total elapsed; switching local category settles only that group, not its members. Each Task stores an exact group-clock entry mark; leaving/admission/terminal materialization subtracts marks exactly. Multiplicity of mutex occurrences remains in Core occupancy; group indexing deduplicates only fanout, never blocker source semantics. Activation-cap running-threshold crossings are handled by a sorted threshold index, not global pending retag.

Category counters are group member cardinalities partitioned into mutex/local-capacity/shared; shared count is interpreted by the one global gate. Thus mutex precedence remains dominant even while the gate is closed. Changed relation-ready membership and changed constraints come only from the exact current typed Core delta, never reconstructed full-set differences. Group creation/seed and complete public per-Task output retain their necessary O(N) work; per-interval maintenance is O(1), and local changes visit only actually indexed affected groups plus changed memberships/threshold crossings.

## 4. Availability and immutable checkpoints

Only delivered requested results determine arithmetic validity. Shared private category/action prefixes may exceed Number range when every actual difference is representable. A requested public scalar that rounds nonfinite makes timing unavailable with existing integral-invalid. Finite clock samples with a nonrepresentable exact difference do not alone invalidate zero-weight results; each requested result is evaluated in exact representation. Negative/backward or throwing/nonfinite clocks retain their existing distinct first-fault classification.

All requested groups share first-fault timing. Validate required aggregate totals at state/checkpoint boundaries, action interval differences before recording their frozen observation, and terminal per-Task outputs before sealing/field getter delivery. Getters never sample or revise validity; read order cannot change availability. Existing old prefix DTOs remain frozen, and later faults do not revise earlier views. Include control/wait/Run-span results in this check, not merely queue delays. Peaks/discrete facts remain available after timing faults.

## 5. Independent executable evidence plan

Production decode/round functions must not be reused as test expectations. Test oracle decodes Number via arithmetic powers/significand (rather than production DataView) into normalized binary rationals; compare exact distances to adjacent binary64 neighbors and ties-even rather than reproducing production bit-shift rounding. An independent low-optimization semantic oracle enumerates relation-ready pending Tasks and applies canonical legality per trace boundary, accumulating each Task/category directly in exact arithmetic.

Deterministic inputs: zero and eta; subnormal/normal boundary; both halfway parities; carry to next exponent; max-finite/overflow half-ulp; negative and cross-zero finite clocks; zero weight with overflowing elapsed; huge prefix then eta local delay; private cumulative prefix beyond max with finite interval; category cycles; heterogeneous claims; multi-source mutex; scope activation/closure and cap thresholds; pending cancellation; nonfinite/backward/throw clock first-fault; captured prefix and field-read permutations. Long alternating-magnitude sequences exercise accumulation order. Seeded randomized traces supplement but do not replace these cases or proof.

Remeasure exact BigInt operations/retained memory under identical before/after runtime/demand workloads. This proof establishes correctness, not measured speed; the adoption matrix must report constant-factor overhead and prefix bit-growth costs explicitly.

## 6. Human-summary derived values are included, not excluded

Summary also delivers three category queue totals and their viable sum, each Task's total admission delay, task-active span, scheduler span, completion-tail span, settled-after-last-admission spans, and root/effective utilization. Discrete counts, peak maxima, ordering metadata, and fingerprint are not floating-point estimators. Top-N ordering compares the final delivered rounded scalar and uses the existing lexical tie break.

Retain exact per-Task breakdown internally through seal. Only an actually enabled diagnostic-summary consumer requests exact per-Task totals and queue totals, formed at terminal from exact breakdowns in necessary O(N) output work. This avoids summing already rounded public DTOs and does not introduce unrequested aggregate maintenance for taskTimings-only consumers. Timestamp spans are exact differences of the existing samples and rounded once. Validate all such requested summary values before any terminal getter or effect observes availability. Public DTO shape does not change.

For utilization, define the exact target R=N/D from exact integral numerator and denominator. A zero denominator or mathematical ratio outside [0,1] retains null. Otherwise evaluate the rational quotient exactly and round once to nearest ties-even: select exponent by exact integer comparison, choose normal 53-bit or subnormal eta quantum, perform integer div/rem, then compare twice the remainder with the divisor and apply even tie parity. This handles underflow correctly rather than asserting every ratio is an integer multiple of eta.

Independently, the direct baseline uses directly accumulated N', D' followed by one binary64 division. On the finite normal relative-bound domain, |N'-N|<=gamma_a N and |D'-D|<=gamma_b D, gamma_b<1; a conservative relative bound after division is ((1+gamma_a)(1+u)/(1-gamma_b)-1). For a subnormal quotient add the absolute half-eta rounding term instead of assuming a relative-only division model. Zero numerator is exact. The candidate RN(N/D) has only the final rounding error: at most uR for a normal result or eta/2 for a subnormal result, and is therefore no worse than the frozen direct quotient guarantee. Direct intermediate overflow/very long sequence domains are covered by the candidate's exact-rational rounding proof, not a relaxed tolerance.

The executable independent oracle must additionally test rational quotient neighbor-distance/tie parity (including below eta/2, eta/2 tie, and above eta/2), zero denominator, and valid values at 0 and 1.

## 7. Run-local exact quantum: a bounded physical representation candidate

The arithmetic proof does not require storing every Number in universal eta units. If the first accepted clock sample t0 is positive and normal, let its unbiased binade exponent be E, obtained from the binary64 exponent bits, and fix q=E-52 for this collector. Every later accepted sample t>=t0 is positive and lies in a binade whose exponent is >=E; therefore it is an exact integer multiple of 2^q. Clock subtraction and integer-weight multiplication remain exact integers in the same immutable unit. If t0<=0 or subnormal (including zero and negative zero), use q=-1074, which covers crossing zero and all finite Number inputs. Never infer q with rounded Math.log2.

Choose q only from the first existing clock call, after the original initial classification/seed work, and before any nonzero numeric contribution. Keep q invocation-local and immutable; shared zero group/Task marks are unit-independent. Clock validation occurs before conversion, so later invalid/backward samples do not enter a coarser unit. No accepted sample is rounded to the chosen unit: exact divisibility is proved from the current clock guard. Independent tests must include power-of-two neighbors, later binade crossings, first value zero/negative/subnormal, multiple Run isolation, and backward/nonfinite/throw first-fault behavior.

Generic conversion rounds U*2^q once: retain at most 53 high bits, apply exact discarded-bit tie parity, then multiply by the exactly representable power 2^(q+discardedBits). q>=-1074 ensures this scale never creates an unmodelled fractional eta contribution; IEEE overflow at the final exponent multiplication is the same correct rounding threshold as in section 2. All local-prefix, availability, and accuracy conclusions are unchanged. In normal positive-clock Runs this avoids retaining roughly 1000 irrelevant trailing zero bits per nonzero BigInt. The eta case remains the proved full-domain unit, not an empirical tolerance or lossy fallback.

This is a representation candidate pending executable oracle checks and measured cost; no adoption claim is made by this note.
